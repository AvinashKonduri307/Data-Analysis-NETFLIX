# Netflix Content Analytics Dashboard

## Project Overview

Developed an interactive Power BI dashboard to analyze Netflix content performance from 2016–2025. The project focuses on understanding content trends, audience engagement, genre popularity, and content quality using IMDb ratings and viewership metrics.

## Objectives

* Analyze Netflix content trends across multiple years.
* Identify the highest-rated and most-viewed titles.
* Explore the relationship between IMDb ratings and audience engagement.
* Understand genre performance and content distribution.
* Deliver business insights through interactive visualizations and KPI-driven reporting.

## Tools & Technologies

* Power BI Desktop
* Power Query
* DAX (Data Analysis Expressions)
* Data Modeling
* Data Visualization

## Data Preparation

* Cleaned and transformed raw Netflix content data using Power Query.
* Standardized viewership metrics and extracted numerical values for analysis.
* Created derived fields such as IMDb Category, Season Number, Total Minutes, and Viewership classifications.
* Handled mixed-format and non-numeric records to improve reporting accuracy.

## Key Metrics

* Total Titles
* Average IMDb Rating
* Total Viewership
* Highest Rated Title
* Most Viewed Title
* Country and Genre Analysis

## Dashboard Features

* KPI Cards for executive-level insights.
* Year-over-Year content performance analysis.
* IMDb rating distribution and quality assessment.
* Viewership trend analysis.
* Genre-based performance comparison.
* Interactive filtering and drill-down capabilities.

## Business Insights

The dashboard enables stakeholders to identify high-performing content categories, evaluate audience preferences, understand content quality trends, and uncover factors influencing viewer engagement.

## Skills Demonstrated

Power BI, Power Query, DAX, Data Cleaning, Data Transformation, Data Modeling, Data Visualization, KPI Development, Dashboard Design, and Business Intelligence Reporting.
